
# Movie Tracking Website

A Flask web application for tracking movies and TV series that I have watched.

The application uses the **TMDB API** to retrieve movie and series information while maintaining its own database for personal watch history and user-specific information.

## Purpose

The problem this application solves is keeping a reliable record of movies and series that I have watched instead of relying on memory.

The application will allow users to:

* Create an account and authenticate.
* Search for movies and TV series using TMDB.
* View movie and series information.
* Mark movies and series as watched.
* Keep a personal watch history.
* Record when something was watched.
* Give personal ratings.
* Add personal notes.
* View and manage their watched content.

## Project Goal

The project is being developed as a practical Flask application while applying software architecture concepts such as:

* Domain modeling
* Service layer
* Repository pattern
* Data persistence
* API integration
* Authentication
* Unit testing
* Integration testing
* End-to-end testing

The goal is to build a complete application while understanding  **why each part exists and how the parts communicate with one another** .
